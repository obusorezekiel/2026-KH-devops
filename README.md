# KodeCamp DevOps Handson

Welcome to the KodeCamp DevOps Handson project! This repository demonstrates basic HTML usage as an introductory exercise.

## Files Included

- **index.html** – Main page with text, basic HTML tags, form inputs, a table, and Google assets.
- **2.html** – Similar practice page with common HTML elements.
- **1.html** – Simple "Hello World" file.

## Features

- Basic HTML tags: paragraphs, headings, links, images, buttons
- Various input types: text, password, email, number, date, time, datetime-local, file
- Table structure demonstration

## Getting Started

1. Clone this repository:
    ```bash
    git clone <repository-url>
    ```
2. Open any of the `.html` files (such as `index.html`) in your web browser to view the page.

## Example Preview

Here is a sample of what you’ll see in `index.html`:

```html
<h1>This is a heading</h1>

<input type="text" placeholder="Enter your name">
<table>
    <tr>
        <th>Name</th>
        <th>Age</th>

        <td>John</td>

```
